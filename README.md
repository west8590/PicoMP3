###### PicoMP3 is a minimalist MP3 player for windows, built to be extremely lightweight (24 KB) while still supporting album art, metadata, and smooth playback. It’s designed for simplicity, speed, and portability.



##### HOW TO USE

1. Create a folder of MP3 files (your playlist)
2. Make sure each file has proper metadata (title, artist, album cover)
3. Run PicoMP3.exe
4. Select your playlist



##### FEATURES

###### Playback controls

* Play / Pause
* Previous track
* Random track
* Auto‑play track

###### File Handling

* Open MP3 files directly
* Drag‑and‑drop support

###### Display

* Album cover (PNG/JPG scaled to comfortably fit 256x256)
* Title and artist metadata
* Playback position
* Volume control



##### CURRENTLY SUPPORTS

Windows

PNG and JPG album covers



##### COMPRESSION PROCESS

1. Creates all images at runtime
2. Uses minimal and smallest external libraries
3. Compress in UPX (compresses the executable and adds a small decompressor)
